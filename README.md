# Celestial Edge

Celestial Edge is a Minecraft plugin that introduces a custom Legendary item with high-quality visuals, smooth animations, and polished combat mechanics. The item features unique particles, a special ability called Sky Laser activated by Shift + Right-Click, and dramatic visual effects. The ability deals 1 heart per second for 4 seconds and reduces armor durability. The code is clean, modular, and optimized, with proper targeting, cooldowns, and cleanup.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/yourusername/CelestialEdge/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Craft the Legendary item using the recipe:
   ```
   D D D
   D S D
   D D D
   ```
   where D is a Diamond Block and S is a Stick.
2. Hold the Legendary item in your main hand.
3. Shift + Right-Click to activate the Sky Laser ability.
4. The Sky Laser will deal 1 heart per second for 4 seconds to nearby players and reduce their armor durability.
